# Hotel Manager

Sistema para gestão e reservas voltado para a hotelaria de experiência (hotel/resort), combinando operação administrativa consistente e portal público com busca semântica em linguagem natural.

> **Status:** **Em Desenvolvimento Ativo**

---

## Stack Tecnológica

* **Backend:** Java 17, Spring Boot 3, Arquitetura Hexagonal, Spring Security (JWT)
* **Frontend:** Next.js, React, TypeScript, Tailwind CSS
* **Persistência:** PostgreSQL (dados transacionais e operacionais) e MongoDB Atlas (catálogo flexível e busca vetorial com embeddings)
* **Infraestrutura:** Docker, Docker Compose, GitHub Actions (CI/CD com Gradle)
